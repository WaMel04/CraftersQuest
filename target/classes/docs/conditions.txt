# CraftersQuest Plugin by WaMel_ (Discord: wamel04)

# QuestConditon의 TriggerCondition 종류에 대해 설명하는 문서입니다.

========================================= ##### Conditions ##### =========================================
PlaceBlockCondition
    형식: PLACE_BLOCK '(블럭)' '(수량)'
    타입: PROGRESSIVE
    인자:
        - 블럭: 설치해야할 블럭의 Material입니다.
        - 수량: 설치해야할 수량입니다.
    설명:
        - 블럭을 설치할 시 충족되는 조건입니다.
    예시: PLACE_BLOCK 'GRASS_BLOCK' '10'
==========================================================================================================
BreakBlockCondition
    형식: BREAK_BLOCK '(블럭)' '(수량)'
    타입: PROGRESSIVE
    인자:
        - 블럭: 파괴해야할 블럭의 Material입니다.
        - 수량: 파괴해야할 수량입니다.
    설명:
        - 블럭을 파괴할 시 충족되는 조건입니다.
    예시: BREAK_BLOCK 'STONE' '10'
==========================================================================================================
EnterCondition
    형식: ENTER '(xMin)' '(yMin)' '(zMin)' '(xMax)' '(yMax)' '(zMax)' '(월드)'
    타입: COMPLETED_ONCE
    인자:
        - xMin: x의 최소입니다.
        - yMin: y의 최소입니다.
        - zMin: z의 최소입니다.
        - xMax: x의 최대입니다.
        - yMax: y의 최대입니다.
        - zMax: z의 최대입니다.
        - 월드: 월드의 이름입니다.
    설명:
        - 특정 좌표 내에 있을 시 충족되는 조건입니다.
        - 좌표에 'x'를 입력 시 해당 부분은 생각하지 않습니다.
    예시: ENTER '-10' 'x' '-10' '10' 'x' '10' 'world' # y 좌표의 최소와 최대를 생각하지 않습니다.
==========================================================================================================
ExitCondition
    형식: EXIT '(xMin)' '(yMin)' '(zMin)' '(xMax)' '(yMax)' '(zMax)' '(월드)'
    타입: COMPLETED_ONCE
    인자:
        - xMin: x의 최소입니다.
        - yMin: y의 최소입니다.
        - zMin: z의 최소입니다.
        - xMax: x의 최대입니다.
        - yMax: y의 최대입니다.
        - zMax: z의 최대입니다.
        - 월드: 월드의 이름입니다.
    설명:
        - 특정 좌표 내에 있지 않을 시 충족되는 조건입니다.
        - 좌표에 'x'를 입력 시 해당 부분은 생각하지 않습니다.
    예시: EXIT '-10' 'x' '-10' '10' 'x' '10' 'world' # y 좌표의 최소와 최대를 생각하지 않습니다.
==========================================================================================================
CommandCondition
    형식: COMMAND '(명령어)'
    타입: COMPLETED_ONCE
    인자:
        - 명령어: 입력해야할 명령어입니다.
    설명:
        - 특정 명령어를 입력할 시 충족되는 조건입니다.
    예시: COMMAND 'me'
==========================================================================================================
TalkCondition
    형식: TALK '(NPC 이름)'
    타입: COMPLETED_ONCE
    인자:
        - NPC 이름: 대화해야 할 npc의 이름입니다.
    설명:
        - 특정 npc와 대화할 시 충족되는 조건입니다.
    예시: TALK '예시_NPC'
==========================================================================================================
EquipCondition
    형식: EQUIP '(아이템)'
    타입: COMPLETED_ONCE
    인자:
        - 아이템:
            - 착용해야할 아이템입니다.
            - 마인크래프트의 Material, 아이템 이름, QuestItem의 ID를 사용할 수 있습니다.
    설명:
        - 특정 아이템을 착용할 시 충족되는 조건입니다.
    예시:
        - EQUIP 'prism_chestplate' (QuestItem으로 구분)
        - EQUIP 'DIAMOND_CHESTPLATE' (타입으로 구분)
        - EQUIP '프리즈마린 갑옷' (이름으로 구분)
==========================================================================================================
KillCondition
    형식: KILL '(엔티티)'
    타입: PROGRESSIVE
    인자:
        - 엔티티:
            - 처치해야할 엔티티입니다.
            - 마인크래프트의 EntityType, 엔티티 이름을 사용할 수 있습니다.
    설명:
        - 특정 엔티티를 죽일 시 충족되는 조건입니다.
    예시:
        - KILL 'PIG' '10'
        - KILL '사그라지는 갑옷병' '15'
==========================================================================================================
CollectItemCondition
    형식: COLLECT_ITEM '(아이템)' '(수량)'
    타입: PROGRESSIVE
    인자:
        - 아이템:
            - 가져와야 할 아이템입니다.
            - 마인크래프트의 Material, 아이템 이름, QuestItem의 ID를 사용할 수 있습니다.
        - 수량: 가져와야 할 수량입니다.
    설명:
        - 인벤토리에 아이템이 들어올 시 조건 충족 여부를 확인합니다.
    예시:
        - COLLECT_ITEM 'SLIME_BALL' '30'
==========================================================================================================
