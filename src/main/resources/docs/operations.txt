# CraftersQuest Plugin by WaMel_ (Discord: wamel04)

# NPC와 Quest 스크립트에서 실행할 수 있는 Operation을 설명하는 문서입니다.
# PlaceHolderAPI와 MineDown을 지원합니다.
# '&'를 색상 코드로 사용할 수 있습니다.
========================================= ##### Operation PlaceHolders ##### =========================================
# 모든 Operation에서 쓸 수 있는 Placeholder입니다.

모든 스크립트에서 사용 가능:
    %player_name%:
        설명:
            - 플레이어의 닉네임입니다.
퀘스트 스크립트에서만 사용 가능:
    %quest_name%:
        설명:
            - 퀘스트의 이름입니다.
    %condition_name%:
        예시:
            - %condition_name%
            - %condition_name:break_block_cond%
        설명:
            - QuestCondition의 ProgressOperations, CompleteOperations 부분에서만 사용할 수 있습니다.
            - 해당 QuestCondition의 이름입니다.
            - %condition_name:(QuestCondition's id)%으로 다른 QuestCondition의 이름을 가져올 수 있습니다.
    %current_progress%:
        예시:
            - %current_progress%
            - %current_progress:break_block_cond%
        설명:
            - QuestCondition의 TriggerCondition 타입이 PROGRESSIVE일 경우에만 사용할 수 있습니다.
            - QuestCondition의 ProgressOperations, CompleteOperations 부분에서만 사용할 수 있습니다.
            - 해당 QuestCondition의 현재 진척도입니다.
            - %current_progress:(QuestCondition's id)%으로 다른 QuestCondition의 현재 진척도를 가져올 수 있습니다.
    %max_progress%:
        예시:
            - %max_progress%
            - %max_progress:break_block_cond%
        설명:
            - QuestCondition의 TriggerCondition 타입이 PROGRESSIVE일 경우에만 사용할 수 있습니다.
            - QuestCondition의 ProgressOperations, CompleteOperations 부분에서만 사용할 수 있습니다.
            - 해당 QuestCondition의 최대 진척도입니다.
            - %max_progress:(QuestCondition's id)%으로 다른 QuestCondition의 최대 진척도를 가져올 수 있습니다.
    %progress_percent%:
        예시:
            - %progress_percent%
            - %progress_percent:break_block_cond%
        설명:
            - QuestCondition의 TriggerCondition 타입이 PROGRESSIVE일 경우에만 사용할 수 있습니다.
            - QuestCondition의 ProgressOperations, CompleteOperations 부분에서만 사용할 수 있습니다.
            - 해당 QuestCondition의 진척률입니다.
            - 소숫점 두자리 수까지 표기합니다.
            - %progress_percent:(QuestCondition's id)%으로 다른 QuestCondition의 진척률을 가져올 수 있습니다.
========================================= ##### Operations ##### =========================================
ActionbarOperation
    형식: $actionbar '(메세지)'
    인자:
        - 메세지: 액션바의 메세지입니다.
    설명:
        - 액션바를 보여줍니다.
    예시: $actionbar '진행도: %current_progress/%max_progress%'
==========================================================================================================
# BossbarOperation
    형식: $bossbar '(색상)' '(스타일)' '(지속 시간)' '(타이틀)'
    인자:
        - 색상: 보스바의 색상입니다. (PINK, BLUE, RED, GREEN, YELLOW, PURPLE, WHITE)
        - 스타일: 보스바의 스타일입니다. (SOLID, SEGMENTED_6, SEGMENTED_10, SEGMENTED_12, SEGMENTED_20)
        - 지속 시간: 보스바의 지속 시간입니다. (타입: 정수, 단위: 초)
        - 타이틀: 보스바의 타이틀입니다.
    PlaceHolder:
        - %remaining_time%: 보스바의 남은 지속 시간입니다.
    설명:
        - 보스바를 지속 시간 동안 보여줍니다.
    예시: $bossbar 'RED' 'SOLID' '10' '&c%remaining_time%초 후 폭탄이 터집니다!'
==========================================================================================================
# TitleOperation
    형식: $title '제목' '부제목' '지속 시간' 'fadein' 'fadeout'
    인자:
        - 제목: 타이틀의 제목(title)입니다.
        - 부제목: 타이틀의 부제목(subtitle)입니다.
        - 지속 시간: 타이틀의 지속 시간입니다. (타입: 정수, 단위: 초)
        - fadein: 타이틀이 완전히 나타날 때까지 소요되는 시간입니다. (타입: 정수, 단위: tick)
        - fadeout: 타이틀이 완전히 사라질 때까지 소요되는 시간입니다. (타입: 정수, 단위: tick)
    설명:
        - 플레이어에게 타이틀을 보여줍니다.
    예시: $title '&a&l축하합니다!' '&f%quest_name% 퀘스트를 완료하셨습니다.' '3' '10' '10'
==========================================================================================================
# SendOperation
    형식: $send '(메세지)'
    인자:
        - 메세지: 플레이어에게 보여질 메세지입니다.
    설명:
        - 플레이어에게 메세지를 보여줍니다.
    예시: $send '안녕하세요'
==========================================================================================================
# PageOperation
    형식: $page '(페이지)'
    인자:
        - 페이지: 플레이어에게 보여질 페이지입니다.
    설명:
        - NPC 스크립트에서만 사용할 수 있습니다.
        - 플레이어와 대화 중인 NPC의 특정 페이지를 보여줍니다.
    예시: $page 'nr_eq_page_2'
==========================================================================================================
# ExitOperation
    형식: $exit
    설명:
        - NPC 스크립트에서만 사용할 수 있습니다.
        - 플레이어의 대화를 종료시킵니다.
    예시: $exit
==========================================================================================================
# SetQuestStateOperation
    형식: $set_quest_state '(퀘스트 ID)' '(퀘스트 상태)'
    인자:
        - 퀘스트 ID: 상태를 설정할 퀘스트의 ID입니다.
        - 퀘스트 상태: 퀘스트의 상태입니다. (NOT_REQUESTED, PROCEEDING, COMPLETED)
    설명:
        - 플레이어의 퀘스트 상태를 설정합니다.
    예시: $set_quest_state 'example_quest_1' 'PROCEEDING'
==========================================================================================================
# ConsoleCommandOperation
    형식: $console_command '(명령어)'
    인자:
        - 명령어: 실행될 명령어입니다.
    설명:
        - 콘솔 권한으로 명령어를 실행시킵니다.
    예시: $console_command 'say 콘솔 메세지'
==========================================================================================================
# PlayerCommandOperation
    형식: $player_command '(명령어)'
    인자:
        - 명령어: 실행될 명령어입니다.
    설명:
        - 플레이어 권한으로 명령어를 실행시킵니다.
    예시: $player_command 'spawn'
==========================================================================================================
# OpCommandOperation
    형식: $op_command '(명령어)'
    인자:
        - 명령어: 실행될 명령어입니다.
    설명:
        - 플레이어가 관리자 권한으로 명령어를 실행시킵니다.
    예시: $op_command 'give %player_name% diamond 1'
==========================================================================================================
# GiveOperation
    형식: $give '(아이템)' '(수량)'
    인자:
        - 아이템:
            - 지급할 아이템입니다.
            - 마인크래프트의 Material, QuestItem의 ID를 사용할 수 있습니다.
        - 수량: 지급할 수량입니다.
    설명:
        - 플레이어에게 아이템을 지급합니다.
        - 공간이 부족할 경우, 바닥에 아이템이 드롭됩니다.
    예시:
        - $give 'DIRT' '10'
        - $give 'ruby' '3'
==========================================================================================================
# ChanceGiveOperation
    형식: $chance_give '(확률)' '(성공 아이템)' '(성공 아이템 수량)' '(실패 아이템)' '(실패 아이템 수량)'
    인자:
        - 확률: 성공 아이템이 지급될 확률입니다. (타입: 유리수)
        - 성공 아이템:
            - 성공 시 지급할 아이템입니다.
            - 마인크래프트의 Material, QuestItem의 ID를 사용할 수 있습니다.
        - 성공 아이템 수량: 성공 시 지급할 아이템의 수량입니다.
        - 실패 아이템:
            - 실패 시 지급할 아이템입니다.
            - '<none>'을 입력시 아무런 아이템도 지급하지 않습니다.
        - 실패 아이템 수량: 실패 시 지급할 아이템의 수량입니다.
    설명:
        - 플레이어에게 확률적으로 아이템을 지급합니다.
        - 공간이 부족할 경우, 바닥에 아이템이 드롭됩니다.
    예시:
        - $chance_give '50' 'crystal' '2' 'ruby' '1'
        - $chance_give '30' 'DIAMOND' '10' '<none>' '0'
==========================================================================================================
